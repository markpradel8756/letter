# A Letter From My Heart

A simple, heartfelt web page designed like a sealed love letter that opens to reveal a personal message, memories, and a quiet confession for you.

This project is built with plain HTML, CSS, and JavaScript, and it creates the feeling of opening an old handwritten letter from a treasured moment in time.

## What this project is

This is a romantic storytelling website made to feel like:

- a handwritten note tucked inside an envelope
- a small memory scrapbook filled with feelings
- a gentle confession put into words
- a keepsake you can give to someone meaningful

## Features

- Envelope opening animation
- Soft vintage paper styling
- Letter and story sections with heartfelt text
- Memory-card layout with decorative details
- Optional photo placeholders for personal images
- Responsive layout for desktop and mobile
- Lightweight setup with no framework required

## Project structure

```text
index.html   - main page and letter content
style.css    - visual design and page styling
script.js    - animations and interactivity
images/      - optional personal photos and icons
```

## Run it locally

Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
